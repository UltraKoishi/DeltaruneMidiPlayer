# Deltarune MIDI Player

[English](README.md) | **Русский**

Windows-приложение для преобразования MIDI-файлов в последовательности клавиш и их воспроизведения в DELTARUNE через AutoHotkey v2.

> Независимый фанатский инструмент. Проект не связан с авторами или издателями DELTARUNE.

## Возможности

- преобразование `.mid` и `.midi` в текстовую последовательность команд;
- сохранение всех активных MIDI-каналов в одном файле композиции;
- выбор и воспроизведение канала прямо в приложении;
- поддержка всех MIDI-событий `Set Tempo` и изменения BPM внутри композиции;
- подробный отчёт о конфликтах полифонии и коротких нотах;
- сохранение только самой высокой ноты в полностью синхронных аккордах;
- воспроизведение через AutoHotkey v2 с горячими клавишами F9/F10;
- настраиваемая горячая клавиша для запуска и остановки записи вместе с воспроизведением (по умолчанию `Numpad7`);
- русский и английский интерфейс;
- системная, светлая и тёмная темы;
- сохранение темы, языка, размера и состояния окна;
- перетаскивание MIDI-файлов прямо в окно;
- копирование и очистка журнала действий.

## Системные требования

Для готового portable-релиза:

- Windows 10/11 x64;
- [AutoHotkey v2](https://www.autohotkey.com/) для воспроизведения последовательностей;
- [Organ Control Expansion](https://gamebanana.com/mods/648107) для полного функционала в игре.

.NET Runtime устанавливать не требуется: релизная сборка является self-contained.

Для сборки из исходников нужен .NET 10 SDK.

## Использование

1. Поместите MIDI-файл в папку `MIDI` или перетащите его в окно приложения.
2. Нажмите **Конвертировать MIDI**.
3. В `NoteSequences` появится один файл, например `song.txt`, содержащий все активные MIDI-каналы.
4. Выберите созданную композицию, затем нужный канал в списке **MIDI-канал** и нажмите **Запустить воспроизведение**.
5. Переключитесь в игру и нажмите F9. Запустится только выбранный канал. F10 закрывает AHK-скрипт.

Для автоматического управления записью OBS откройте **Параметры**, включите **Запускать и останавливать запись вместе с воспроизведением** и выберите ту же клавишу, которая настроена в OBS. По умолчанию используется `Numpad7`. Клавиша нажимается перед первой нотой и повторно после последней; остановка AHK-скрипта также завершает активную запись.

## Обработка одновременных нот

Каждый MIDI-канал проверяется и экспортируется как отдельная монофоническая последовательность. Ноты разных каналов не создают конфликтов, потому что воспроизводится только выбранный канал:

- если несколько нот начинаются и заканчиваются одновременно, сохраняется самая высокая нота, а остальные перечисляются в предупреждении;
- если одновременно начавшиеся ноты имеют разную длительность или ноты перекрываются при разных моментах начала, конвертация останавливается;
- весь MIDI проверяется целиком, поэтому журнал показывает полный пронумерованный список конфликтов;
- точные дубликаты одной и той же ноты не считаются отдельным конфликтом.

## Формат последовательности

```text
[Channel 1]
Instrument|3
C4|100
Sleep|250

[Channel 2]
E4|100
```

## Настройки

Пользовательские настройки сохраняются в:

```text
%LOCALAPPDATA%\DeltaruneMidiPlayer\settings.json
```

## Сборка из исходников

```powershell
dotnet build DeltaruneMidiPlayer.csproj
```

## Создание релиза

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish.ps1
```

Скрипт создаёт автономную single-file сборку для Windows x64 и ZIP-архив в папке `artifacts`.
